## Introduction

Managarm is an asynchronous microkernel-based operating system that aims for source-level compatibility with Linux software. Over time, this compatibility has grown to cover increasingly complex desktop applications and frameworks. We recently reached another milestone: running [GNOME Web, also known as Epiphany](https://apps.gnome.org/Epiphany/), on Managarm.
